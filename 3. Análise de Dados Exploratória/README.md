# Projeto ADE

## Objetivos
- explorar e compreender conjuntos de dados
- identificar padrões, tendências e relações entre variáveis
- analisar a distribuição e qualidade dos dados
- aplicar técnicas de análise exploratória e estatística
- utilizar visualizações para apoiar a interpretação dos dados

## Ferramentas
- Python (Pandas, NumPy, etc.)
- Matplotlib, Seaborn
- SciPy / Statsmodels
