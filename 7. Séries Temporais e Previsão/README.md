# Projeto STP

## Objetivos
- analisar séries temporais e identificar tendências e padrões sazonais
- desenvolver e aplicar modelos de previsão
- comparar diferentes abordagens de forecasting
- avaliar o desempenho das previsões através de métricas adequadas

## Ferramentas
- Python (Pandas, NumPy, Scikit-learn, etc.)
- Matplotlib, Seaborn
- Statsmodels
- SciPy
