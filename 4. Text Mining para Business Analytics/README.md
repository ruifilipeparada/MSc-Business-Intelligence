# Projeto TMBA

## Objetivos
- aplicar técnicas de Text Mining a dados textuais
- realizar pré-processamento e análise de texto
- extrair informação e padrões relevantes de documentos
- aplicar técnicas de Natural Language Processing (NLP)
- analisar e interpretar os resultados obtidos

## Ferramentas
- Python
- Pandas, NumPy
- NLTK / spaCy
- Scikit-learn
